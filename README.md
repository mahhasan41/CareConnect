# CareConnect: Assistance & Social Connection Platform

## 📖 Project Overview
**CareConnect** is a web-based platform designed to connect individuals needing daily assistance with trusted service providers called **CareMates**. The system enables users to request help, set reminders, track mood, and engage socially, while CareMates accept tasks based on urgency and availability. The platform ensures **accessibility, reliability, and community support** for users of all age groups.

## ✨ Features
- **Help Request System**: Users can request assistance for daily tasks (e.g., transportation, shopping, medical needs).
- **Reminders & Mood Tracking**: Set reminders and update mood logs for better personal well-being.
- **Social Engagement**: Post and interact within the community.
- **Urgency-Based Task Assignment**: CareMates accept tasks based on urgency and availability.
- **Payment Integration**: Secure and seamless payment flow for services.
- **Verified CareMates**: Trusted, community-driven professionals.
